# 💬 Flutter Chat App

## 📌 Description

A real-time chat application built using Flutter and Firebase.  
This app allows users to communicate seamlessly with features like authentication, messaging, and media sharing.

---

## 🚀 Features

- 🔐 Google Sign-In Authentication
- 💬 Real-time one-to-one chat
- 🖼️ Send images and stickers
- 👤 User profile & avatar update
- ☁️ Firebase Firestore integration
- 📦 Firebase Storage for media

---

## 🛠️ Tech Stack

- Flutter (Dart)
- Firebase Authentication
- Cloud Firestore
- Firebase Storage

## ⚙️ Setup Instructions

1. **Clone the repository:**
```bash
   git clone https://github.com/11iamvikas/flutter-chat-app.git
```

2. **Navigate to project folder:**
```bash
   cd flutter-chat-app
```

3. **Install dependencies:**
```bash
   flutter pub get
```

4. **Add your Firebase configuration:**
   - Place `google-services.json` inside:
```
     android/app/
```

5. **Run the app:**
```bash
   flutter run
```
